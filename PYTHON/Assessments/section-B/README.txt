# Data Analytics - Module 6 - Section B

Four Python source files are included, one per task.

## How to run
Open PowerShell or the VS Code terminal in this folder and run:

```powershell
python task1_delivery_fee_calculator.py
python task2_restaurant_menu_manager.py
python task3_order_history_file_logger.py
python task4_delivery_rider_oop_system.py
```

Tasks 3 and 4 create `orders.json` and `riders.csv` in the current working directory when you use them.

The PNG files are illustrative sample console-output captures generated using sample inputs. Run each `.py` file on your own computer and capture your actual console output for submission if your instructor requires screenshots from your system.
